Dropbox

Conecta Dropbox desde QuantPower Builder para explorar tus carpetas y elegir qué archivos obtener.

Disponibilidad del login: la instalación debe incluir la App key OAuth pública (QPB_DROPBOX_APP_KEY) y la App Console de Dropbox debe tener registrada la URI de retorno http://127.0.0.1:53682/oauth2/callback (o la configurada en QPB_DROPBOX_REDIRECT_URI).

Versión: v0.7.6.2 Redactada: 9 de octubre de 2026

Conexión online: la aplicación solicita autorización a Dropbox para consultar y descargar los archivos que selecciones. No se requiere instalar ni mantener abierta la aplicación de escritorio de Dropbox.

Conectar Dropbox

  1. Comprueba que tu cuenta tiene acceso a los archivos y carpetas que quieres utilizar.
  2. En QuantPower Builder, abre Descargar → + Añadir fuente → Contenedor → Dropbox y pulsa Conectar con Dropbox.
  3. Inicia sesión en la página de Dropbox, revisa los permisos que se muestran y autoriza el acceso para regresar a la aplicación.
  4. Pulsa Elegir carpeta…, selecciona la carpeta que quieres explorar y pulsa Guardar conexión. El catálogo consultará esa ubicación y sus subcarpetas sin crear una copia sincronizada.

Configurar y obtener archivos

Descargar → + Añadir fuente → Contenedor → Dropbox
  1. Asigna un nombre para identificar la ubicación de Dropbox.
  2. Pulsa Actualizar catálogo para consultar los archivos remotos compatibles.
  3. Selecciona una o varias series y pulsa el botón de descarga. Para elegir archivos concretos de un ZIP, ábrelo y selecciona sus miembros.
  4. Las copias se guardan en la biblioteca local, dentro de la fuente Dropbox. Abre Importar → Fuentes → Dropbox para localizarlas; los originales en Dropbox no se mueven ni se modifican.

Actualizaciones

Cuando haya nuevos archivos, actualiza el catálogo para volver a consultar Dropbox. La descarga ocurre al obtener cada archivo seleccionado; no se fusionan automáticamente con los datos ya importados ni se ejecuta limpieza en segundo plano. Si retiras el permiso de la cuenta, vuelve a conectar Dropbox desde el contenedor.
