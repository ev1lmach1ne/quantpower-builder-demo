MEGA

Trabaja con los archivos que MEGA Desktop haya descargado a una carpeta del equipo.

Versión: v0.7.6.2 Redactada: 7 de octubre de 2026

Acceso actual: carpeta sincronizada. La descarga y el descifrado los realiza el cliente de MEGA. QuantPower Builder no pide la cuenta, la contraseña ni claves de MEGA.

Preparar MEGA

  1. Instala MEGA Desktop ↗ e inicia sesión.
  2. Configura una sincronización de la carpeta de históricos con una ubicación local. También puedes descargar los archivos a una carpeta normal.
  3. Espera a que las transferencias terminen y abre un CSV o ZIP desde el Explorador para confirmar su disponibilidad.

Configurar en Descargar

Descargar → + Añadir fuente → Contenedor → MEGA
  1. Da un nombre al contenedor, elige la carpeta local y guarda.
  2. Actualiza el catálogo después de terminar la sincronización.
  3. Selecciona un archivo compatible y pulsa Obtener archivo.
  4. Revisa y limpia la copia obtenida desde Importar.

Qué implica esta modalidad

El catálogo examina archivos locales legibles, no enlaces web de MEGA ni archivos cifrados sin descargar. Una conexión directa a MEGA desde la aplicación requeriría integrar su SDK y todavía no está implementada.
