OneDrive

Obtén archivos desde la carpeta de OneDrive que ya está sincronizada en tu ordenador.

Versión: v0.7.6.2 Redactada: 7 de octubre de 2026

Acceso actual: carpeta sincronizada. La cuenta Microsoft se configura en OneDrive. La aplicación todavía no inicia sesión mediante Microsoft Graph.

Preparar OneDrive

  1. Abre el cliente OneDrive de Windows o instala la aplicación de escritorio ↗.
  2. Inicia sesión con la cuenta que contiene los históricos y selecciona las carpetas que vas a sincronizar.
  3. En el Explorador, marca la carpeta de datos con Mantener siempre en este dispositivo. Espera a que sus archivos estén descargados, no solo representados como archivos bajo demanda.
  4. Comprueba su ubicación local y que puedes abrir los CSV o ZIP.

Configurar y utilizar

Descargar → + Añadir fuente → Contenedor → OneDrive
  1. Escribe un nombre, por ejemplo «OneDrive — Históricos».
  2. Selecciona la carpeta local con Elegir carpeta y guarda.
  3. Actualiza el catálogo, selecciona un archivo y pulsa Obtener archivo.
  4. Ve a Importar para revisar y limpiar la copia obtenida.

Cuando cambien los archivos

Deja que OneDrive termine la sincronización antes de volver a actualizar el catálogo. Si el cliente cambia de ubicación, edita la ruta con Configurar. Quitar el contenedor conserva los archivos de OneDrive.
