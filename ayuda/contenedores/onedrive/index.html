OneDrive

Conecta tu cuenta de OneDrive y elige archivos remotos sin sincronizar toda la carpeta con el equipo.

Versión: v0.7.6.2 Redactada: 7 de octubre de 2026

Conexión online: la autorización se realiza en la página oficial de Microsoft. QuantPower Builder consulta las carpetas a las que tiene acceso la cuenta conectada.

Conectar OneDrive

  1. Comprueba que la cuenta Microsoft tiene acceso a las carpetas que quieres usar.
  2. En la aplicación, abre Descargar → + Añadir fuente → Contenedor → OneDrive y pulsa Conectar.
  3. Inicia sesión en el navegador, revisa el permiso de lectura solicitado y autoriza el acceso para regresar a QuantPower Builder.
  4. Selecciona la carpeta remota. El catálogo consultará su contenido online, incluidos los archivos compartidos disponibles para esa cuenta.

Configurar y utilizar

Descargar → + Añadir fuente → Contenedor → OneDrive
  1. Asigna un nombre para identificar el contenedor y guarda.
  2. Pulsa Actualizar catálogo para consultar el contenido remoto.
  3. Selecciona un archivo y pulsa Obtener archivo para descargar una copia a la biblioteca.
  4. Ve a Importar para revisar y procesar la copia.

Cuando cambien los archivos

Cuando añadas o cambies archivos en OneDrive, actualiza el catálogo para consultar el estado remoto más reciente. Si la autorización caduca o se revoca, conecta de nuevo la cuenta. Quitar el contenedor no elimina los archivos del servicio.
