OneDrive

Información para usuarios con archivos locales descargados mediante versiones anteriores.

Proveedor retirado: OneDrive ya no está disponible para crear conexiones ni descargar archivos en esta versión. Los archivos que ya se descargaron permanecen en la biblioteca local y se pueden seguir usando desde Importar.

Versión: v0.7.6.2 Redactada: 7 de octubre de 2026

Acceder a archivos ya descargados

Abre Importar y localiza los archivos guardados en la carpeta de datos configurada. Retirar el proveedor no borra ni mueve esas descargas.
