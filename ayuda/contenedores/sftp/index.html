SFTP

SFTP permite transferir archivos desde un servidor. En esta entrega se utilizan los archivos que hayas descargado previamente al equipo.

Versión: v0.7.6.2 Redactada: 7 de octubre de 2026

Acceso actual: archivos descargados. Elegir SFTP en la tarjeta identifica el origen del almacenamiento. La aplicación todavía no abre una conexión SFTP ni pide sus credenciales.

Descargar con un cliente SFTP

  1. Obtén del proveedor el servidor, puerto, usuario y método de acceso: contraseña o clave SSH. Son los datos de transferencia de archivos, no una API Key de mercado.
  2. En Windows puedes usar WinSCP ↗. Crea una sesión SFTP con los datos que te dieron; el puerto habitual es 22, pero utiliza el especificado por el proveedor.
  3. El cliente puede pedir que compruebes la identidad del servidor. Contrasta su huella con la proporcionada por el administrador o proveedor.
  4. Navega a la carpeta de datos y descarga los CSV/TXT/ZIP a una ubicación estable del ordenador.
  5. Espera a que se complete la transferencia antes de catalogar los archivos.

Añadir la carpeta de destino

Descargar → + Añadir fuente → Contenedor → SFTP
  1. Escribe un nombre, por ejemplo «SFTP — Históricos».
  2. Pulsa Elegir carpeta y selecciona la ubicación donde descargaste los archivos; guarda el contenedor.
  3. Actualiza el catálogo, selecciona un archivo y pulsa Obtener archivo.
  4. Desde Importar, revisa los datos y ejecuta Limpiar.

Cuando haya más datos

Descarga los archivos nuevos con el cliente SFTP y después actualiza el catálogo. No hay sincronización automática ni descarga remota desde QuantPower Builder en este modo.
